# OBSIDIAN — External Attack Surface Monitoring

A responsive, dark editorial concept site for a fictional cybersecurity product. This portfolio piece intentionally combines a product-marketing page with an interactive security-dashboard demo.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL. Build for production with `npm run build`.

## Included interactions

- Responsive mobile navigation
- Scroll reveal animations with reduced-motion support
- Exposure severity filters and keyword search
- Simulated scan that updates sample metrics and inserts fictional findings
- Detail dialogs for sample findings
- Walkthrough request form with client-side validation and a demo confirmation
- Accessible dialog close behavior and live status announcements

## Important

This is a **fictional portfolio demo**. All metrics, organizations, hostnames, and findings are sample data. The scan button does not send network requests and does not test real systems. The walkthrough form does not transmit or store personal information. There are no API keys or external service integrations.
